# Final candidate blends

Six predeclared additive point corrections preserve practical-combined. Each complete blend is clamped to [-4,4] after weighting. There is no baseline value in this module. Terminal and zero-future-action results are zero. Import direction is final → development/efficiency → catalog/scoring; no leaf or core circular dependency.

Let S = slot-scarcity, R = robust-value, E = engine-saturation, B = bonus-card-option, G = grassland-foundation and T = tuck-card-opportunity, using the existing adjustment helpers.

| Evaluator | Correction before final clamp |
| --- | --- |
| final-space-robust | .5S + .5R |
| final-space-saturation | .5S + .5E |
| final-robust-saturation | .5R + .5E |
| final-space-robust-saturation | (S + R + E)/3 |
| final-development-options | .35S + .35B + .30G |
| final-cautious-portfolio | .25S + .25R + .25E + .25T |

These are blends of distinct prior mechanisms, not six new mechanisms. They preserve the baseline and reduce the maximum size of unconfirmed adjustments. The latest supplied confirmation evidence establishes no clear winner: robust-value was 53.3% with +.53 mean margin; slot-scarcity was 50.8% with +2.07; predator-expectation was 38.3% with -1.7 and is excluded. These figures are context supplied by the coordinator, not results generated by this implementation.

All source-helper limitations remain: approximate future action allocation, food shadow prices, card opportunities and opponent event likelihood; canonical rather than exhaustive egg payments; finite current resource forecasts rather than exact future simulation. Only actor private cards and public board information are used. No hidden deck, opponent private card or tucked-identity reads are introduced. The fixed weights and caps are hypotheses requiring fresh paired evaluation, not calibrated win probabilities.
