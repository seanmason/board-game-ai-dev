Method and limitations

Intervals use independent setup-group averages. A group enters the estimate only when every seat finishes. Caps, unresolved rules and errors stay visible; they are never counted as draws or losses. Results with missing groups can be biased by which games completed.

Each game keeps its own modest search budget. The selected study specifies whether budgets use samples or requested time; measured decision latency shows actual cost. Screening results do not change production AI settings. Jaipur uses a documented assumed token inventory; other source limits remain in each game’s documentation.

Snapshots may be cached for several minutes. “Last update” is the runner’s timestamp, not proof that a process is still alive. A stale running snapshot is marked accordingly.
